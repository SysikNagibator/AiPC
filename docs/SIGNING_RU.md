# Подпись и SmartScreen — честная инструкция

## Почему Windows показывает синий экран «Защитник Windows защитил компьютер»

У `AiPC_Win_1.0.5.1.exe` нет **цифровой подписи код-подписи** и нет **репутации в SmartScreen**.
Windows не знает издателя → перестраховывается. Это нормально для новых
неподписанных программ, это не вирус.

Убрать этот экран полностью может **только сертификат код-подписи**.
Самоподписной сертификат **не поможет** — SmartScreen ему не доверяет.

## Варианты сертификата

| Вариант | Цена | Эффект |
|---------|------|--------|
| **EV Code Signing** | ~$300–500/год | Доверие SmartScreen **сразу**, синего экрана нет с первого скачивания |
| **OV Code Signing** (Sectigo/Comodo через реселлеров) | ~$80–200/год | Подпись есть сразу, синий экран пропадает **по мере набора скачиваний** (репутация) |
| **Certum Open Source** | ~€25/год | Дешёвый OV для открытых проектов — AiPC подходит (публичный репозиторий, MIT). Самый разумный старт |

Понадобится PFX-файл + пароль. Храни вне репозитория!

## Как подписать релиз

```bat
set AIPC_CERT=C:\certs\s1steam.pfx
set AIPC_CERT_PASS=твой_пароль
tools\sign.bat
```

Скрипт подпишет `dist\AiPC_Win_1.0.5.1.exe` (и `AiPC-Setup.exe`) через `signtool`
с меткой времени DigiCert и проверит подпись. Нужен установленный
Windows SDK (там живёт `signtool`).

## Бесплатные шаги (сделать в любом случае)

1. **Отправить файл в Microsoft на проверку:**
   https://www.microsoft.com/en-us/wdsi/filesubmission —
   выбрать «Software Developer», приложить `AiPC_Win_1.0.5.1.exe`. Это снимает
   ложные детекты Defender и ускоряет набор репутации SmartScreen.
2. **Не менять имя файла** между релизами (`AiPC_Win_1.0.5.1.exe`) — репутация
   привязана к имени + подписи.
3. **Набирать скачивания** — SmartScreen учится: чем больше людей
   запускают файл и жмут «Выполнить в любом случае», тем быстрее
   предупреждение исчезнет само.
4. В exe уже вшиты иконка и version-info (издатель S1sTeam во вкладке
   «Подробно» свойств файла) — это тоже плюс к доверию.

## После покупки сертификата

1. Подписать exe через `tools\sign.bat`.
2. Выпустить новый релиз (например v1.0.2) уже с подписанным файлом.
3. EV даст чистый запуск сразу; OV — чистый запуск после набора репутации.
