# Как контрибьютить в AiPC

## Базовые правила

1. **Без коммитов/пушей без аппрува мейнтейнера** — PR, ждём ревью.
2. **Тесты на каждое изменение поведения**, особенно безопасности (включая
   негативные/обходные). Перед пушем: `python -m pytest tests -q`.
3. **Совместимость конфига**: не стирать пользовательское в
   `~/.aipc/config.yaml`. Новые ключи — через `DEFAULTS` + мержи `safety.version`.
4. **Без тяжёлых зависимостей без обоснования** (зачем — в PR).
5. **Доки синхронно**: `README.md` ↔ `README_RU.md`, `SKILL.md` ↔ `SKILL_RU.md`.
   После правок: `python tools/gen_tools_table.py --check`.
6. **CHANGELOG.md** — запись на каждое изменение (секция `[Unreleased]`).

## Чек-лист PR

- [ ] Тесты добавлены/обновлены, сьют зелёный
- [ ] CHANGELOG обновлён
- [ ] Доки синхронны (EN/RU)
- [ ] Секретов в коде и логах нет (см. `aipc/audit.py:mask_secrets`)
- [ ] Изменения безопасности сверены с `docs/THREAT_MODEL_RU.md`
