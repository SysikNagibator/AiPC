### Добавлено (этап 1.5: аудит и аварийный стоп)
- `audit.log` — структурированный JSON-lines: `ts/tool/args(mode...)/mode/decision/ok/note`; секреты маскируются; старые текстовые строки пропускаются при чтении.
- `aipc audit --tail N --since ISO --tool NAME` — просмотр событий.
- Kill switch: файл `~/.aipc/panic` блокирует ВСЕ tools мгновенно (проверка первая в `_wrap`); снять может только человек (`aipc panic --off`). Глобальная горячая клавиша Ctrl+Alt+Shift+K ставит PANIC из любого места (поток RegisterHotKey, best-effort).
- Лимиты: `safety.max_calls_per_min` (по умолчанию 120) → `rate_limited`; один и тот же вызов N раз подряд (`safety.loop_repeat`, по умолчанию 10) → `loop_guard`; скачивание упирается в `safety.max_download_mb` (по умолчанию 200, частичный файл удаляется).
- Исправлено: частичный файл при `too_big` не удалялся на Windows (открытый хендл).
- Тесты: `tests/test_audit_panic.py` (9) — JSON-формат, фильтры, panic блокирует/снимается, rate/loop лимиты, локальный HTTP-тест капа, CLI.

### Добавлено (этап 1.3: защита от prompt injection)

- `ssh_exec` проверяет команду через deny-лист; `ssh_sftp_put` проверяет локальный путь.
- `config.example.yaml` синхронизирован с дефолтами (deny-списки, `lang`, `safety.version`, новые ключи).

### Добавлено (этап 1.1: серверные подтверждения)

- Клавиатура/мышь в чувствительных окнах (менеджеры паролей, крипто, банки + `safety.sensitive_windows_extra`) тоже требуют подтверждения.
