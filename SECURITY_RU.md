# Политика безопасности

## Поддерживаемые версии

Фиксы безопасности получает только последний релиз (ветка `main`).

## Как сообщить об уязвимости

**Не открывайте публичный issue.** GitHub → *Security* → *Report a
vulnerability* (приватный advisory).

Приложите: версию AiPC (`aipc --version`), режим (`ask`/`auto`/`read-only`),
имя tool и параметры (секреты затрите), кусок `audit.log`, ожидаемое
и фактическое поведение.

Подтверждаем в течение 7 дней. Дайте разумное окно на фикс до публичного
раскрытия (максимум 90 дней).

## Замечания о скоупе

- `self_update` качает бинарники релизов с проверкой только MZ-заголовка
  (см. `docs/THREAT_MODEL_RU.md`). Сообщения о подмене бинарника — в скоупе.
- Prompt-инъекции *против модели* — известная открытая проблема; принимаются,
  когда показан обход **на стороне сервера** (нет подтверждения, нет метки
  `untrusted`, инъекция в лог).
- Режим `auto`, выполнивший опасное действие, — не уязвимость, это и есть
  `auto`. Используйте `ask`.
