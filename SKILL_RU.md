# Навык AiPC — полный доступ к ПК для любого coding-агента

Дайте агенту «это» — и он получает полноценный доступ к реальному ПК: экран, мышь, клавиатура, браузер пользователя, файлы, терминал, SSH — через 63 MCP-инструмента.

## Установка в агент (2 минуты)

**Любой MCP-клиент** (Cursor, Claude Code/Desktop, VS Code, Antigravity, Windsurf, Zed, Cline, OpenCode, Gemini CLI, Codex CLI и ещё 30+ — полная таблица находится в `docs/IDES.md`):

```json
{
  "mcpServers": {
    "aipc": {
      "command": "C:\\Program Files\\AiPC\\aipc.exe",
      "args": ["mcp"]
    }
  }
}
```

Нет `C:\Program Files\AiPC`? Используйте portable-версию:

```json
{
  "mcpServers": {
    "aipc": {
      "command": "C:\\path\\to\\aipc.exe",
      "args": ["mcp"]
    }
  }
}
```

После этого перезапустите агент/MCP-серверы. Проверьте работу с помощью `aipc_status` — он должен вернуть:

```json
{"ok": true, ...}
```

## Как агент должен работать

Системный промпт для использования (он также предоставляется через MCP-промпт `aipc_instructions`):

> У ТЕБЯ ЕСТЬ полный доступ к ПК пользователя через инструменты `aipc.*`. Никогда не говори, что у тебя нет доступа к компьютеру. Чтобы увидеть экран, вызывай `screen_see`. Работай по циклу: увидеть → выполнить действие → снова увидеть для проверки. Опасные действия выполняй только после `ask_user`. Вместо перечисления объектов используй поиск: `ui_find` / `window_find` / `fs_find` / `process_find`. Вместо `sleep` используй ожидание: `wait_for_window` / `wait_for_ui_element` / `wait_for_change`.

Основные принципы:

* **Просмотр:** `screen_see` (нативный блок изображения, курсор отмечен) → действие → повторный `screen_see`.
* **Точные клики:** `ui_find` / `ui_snapshot` возвращают готовые координаты `x/y` в диапазоне 0–1000.
* **Ввод текста:** ИСПОЛЬЗУЙТЕ ТОЛЬКО `focus_type` (проверяет фокус и выполняет атомарный ввод).
